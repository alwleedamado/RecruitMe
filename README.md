# RecruitMe

RecruitMe is a professional Online Recruitment Management System.

## Technology Stack

### Backend

- ASP.NET Core 10 Web API
- Entity Framework Core
- SQL Server
- ASP.NET Core Identity
- JWT Authentication
- Clean Architecture
- Repository Pattern
- Unit of Work
- AutoMapper
- FluentValidation
- Serilog

### Frontend

- Angular 21
- PrimeNG
- SCSS

## Solution Structure

```
backend/
frontend/
docs/
scripts/
```

## Getting Started

Backend

```bash
cd backend
dotnet restore
dotnet run --project src/RecruitMe.Api
```

Frontend

```bash
cd frontend/recruitme
npm install
ng serve
```
